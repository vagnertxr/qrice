description=Skin manager for QGIS: rice themes, mascots over the map, palettes from pictures, flags and tiling/zen window layouts. One click on, one click off.
about=QRice turns QGIS into something you can rice. A skin gives QGIS a rounded, gapped theme with colours you pick or take from a picture (pywal style), a mascot in a corner of the map (it lets clicks through and never appears in exports or layouts), a faded picture behind the panes, a focus frame on the active pane, a polybar-style status bar, and window layouts: tiling, zen (map only) or the ArcGIS Pro-style ribbon and panes inherited from ArcSkin by EnviroSolutions. Ships with freely licensed mascots (Tux, Tux Redesign, Wikipe-tan) and every country flag; make your own skin from any picture in the Skin Manager. Switching the skin off restores QGIS exactly as it was. Based on ArcSkin (GPL-2.0) by EnviroSolutions; not affiliated with or endorsed by Esri.

changelog=
    0.5.1 - Skin Manager: position (corner) and distance from the edge for the picture behind the Layers pane, so a character cut off at the bottom can be lifted. README: installation from the Releases tab.
    0.5.0 - QRice: skins (theme, palette from a picture, mascot over the map, faded pane picture, window chrome, layout) with a Skin Manager; rice theme with gaps, rounded corners, focus frame and polybar status bar; tiling and zen layouts; country flag skins; bundled Tux, Tux Redesign and Wikipe-tan skins; the ArcGIS Pro look is now the Pro Light skin. Portuguese translation of the new strings.
    0.4.5 - Switching the look off after an attribute table had been opened and closed no longer ends in a Python error with QGIS only half restored; a step that fails while restoring no longer stops the others.
    0.4.4 - No crash when the skin is switched on while the QGIS message bar is not in the main window's layout (moved by another plugin); the bar then stays where it is.
    0.4.3 - QGIS 3.44: the view tabs above the map are no longer covered by the QGIS message bar; the demo project opens with its coordinate system and map in QGIS 3.44 too.
    0.4.2 - QGIS 3.44: no crash when the plugin is installed into a running QGIS (locator results anchored once the search box is in the window) and the Contents raster legend works (old name of a method); a failed switch restores the toolbars.
    0.4.1 - Typed UTM and metre / kilometre coordinates are understood with English digit grouping (5,786,587).
    0.4.0 - The ribbon reaches all of QGIS: Edit tab with the advanced digitizing tools, shapes, digitizing techniques, all snapping options and the Advanced Digitizing panel; QGIS's Vector, Raster, Database, Web, Mesh, Panels, Toolbars and Decorations menus under ribbon buttons; recent projects, revert, close, import/export and settings in the Project menu. Ribbon tabs scroll sideways in narrow windows instead of widening the window. Faster start (the icon theme and colour ramps are not rewritten when unchanged). Typed coordinates with digit group separators are understood; point and line layers get Pro's default symbols too.
    0.3.1 - Attribute table changes are undone when the look is switched off; a failure while switching leaves plain QGIS; pausing drawing and the grid do not outlive the look; guards for QGIS builds lacking a widget or action; icon files that cannot be written are skipped with a warning.
    0.3.0 - View tabs showing one map view at a time (with its own layers in Contents and extent), 3D views and layouts as tabs; Pro colour ramps, label font and pastel raster icons; Pro-style Symbology pane; lighter icon outlines; progress box while switching; search results drop down; fixes for QGIS 4 (layout tabs, 3D view crash, layer and Browser icons restored when switching off).
    0.2.0 - Ribbon, Pro-style panes, map status bar (coordinates in DD/DMS/DDM, MGRS, USNG, UTM and linear units), basemap gallery, icon theme for all QGIS icons, Pro default symbology and selection color, attribute table, translations (English, Polish), QGIS 4 support.
    0.1.0 - Plugin skeleton, light theme applied/reverted by the plugin.
